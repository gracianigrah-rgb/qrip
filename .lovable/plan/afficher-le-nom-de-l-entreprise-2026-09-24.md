# Afficher le nom de l’entreprise

## Modifications
- Afficher le nom du profil en haut à droite de la carte « Solde de l’activité » sur l’accueil.
- Afficher ce même nom dans le rapport à l’écran.
- Inclure le nom de l’entreprise dans le texte partagé, l’export CSV et l’export PDF.
- Utiliser « Mon entreprise » si le profil n’est pas encore complété, sans bloquer l’affichage.

## Vérification
- Vérifier sur mobile que les noms longs restent lisibles sans chevaucher le solde.
- Vérifier que les téléchargements CSV et PDF contiennent bien le nom.
